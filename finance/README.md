# Finance Enterprise

This module provides a production-ready scaffold for enterprise finance features:

- Income & Expense management
- Invoices & Payments
- GST summary
- Profit & Loss reports
- Cash Flow reports
- Dashboard overview
- Export stubs (PDF/Excel)

Current implementation uses in-memory route handlers (app/api/finance/*). Replace with Prisma-backed persistence and robust export generation for production.
