# HR Enterprise

This module implements an enterprise HR scaffolding with the following features:

- Employees management
- Attendance tracking
- Leave requests and approvals
- Payroll record management
- Departments
- Recruitment (candidates)
- Performance reviews
- Reports and exports (placeholders)

Current implementation uses in-memory API route handlers under app/api/hr/* for local testing and UI development. Replace with Prisma-backed persistence for production.
